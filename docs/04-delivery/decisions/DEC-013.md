# DEC-013 — Verificación de correo obligatoria

**Estado:** APPROVED
**Fecha:** 2026-08-05

## Decisión

La verificación de correo electrónico es **obligatoria** para toda cuenta, incluida la del peregrino. Una inscripción no se completa mientras el correo no esté verificado.

## Motivo

El correo es el canal por el que llegan el Comprobante de pago, los avisos de revisión de evidencia y las notificaciones operativas. Una dirección no verificada significa un peregrino al que el sistema no puede contactar cuando su evidencia se rechaza o cuando cambia información del evento.

## Consecuencias

- El registro emite un token de verificación de un solo uso y con vencimiento, almacenado por hash.
- El envío ocurre por el worker, no en la petición: una caída de SMTP no debe revertir la creación de la cuenta (GOV-008).
- La cuenta existe en estado no verificado; lo que se bloquea es completar la inscripción, no crear la cuenta.
- El reenvío del correo de verificación debe tener rate limit, por ser una superficie accesible sin sesión.
- Las cuentas creadas por Inscripciones para inscripción presencial necesitan un camino previsto: el peregrino puede no tener correo accesible en ese momento. Queda como TBD dependiente de DEC-006.
