# Scripts del paquete

- `validate_canonical_docs.py`: valida estructura, contratos y decisiones consolidadas.
- `rebuild_package_v2_7.py`: reconstruye en el mismo directorio los documentos fuente, contratos, prototipo y DOCX generados. No elimina el paquete raíz.

La reconstrucción sobrescribe archivos de v2.7. Ejecútela únicamente en una copia o rama controlada y revise `git diff`.
